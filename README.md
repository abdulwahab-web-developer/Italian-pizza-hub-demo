# Italian Pizza Hub Website

A restaurant website concept created for **Italian Pizza Hub, Kebab & Pasta**.

## About This Project

This project is a **website showcase/concept design** created to demonstrate a possible modern online presence for a restaurant.

Please note: this is **not a complete final website design** and does not include full restaurant functionality such as online ordering, payment processing, booking systems, or restaurant management integrations.

The purpose of this project is to showcase the visual design, layout, user experience, and front-end development approach.

## Built With

* HTML5
* CSS3
* JavaScript

## Features

* Modern restaurant landing page design
* Responsive layout for desktop, tablet, and mobile
* Food menu showcase
* Restaurant branding concept
* Image gallery section
* Contact section
* Smooth UI interactions and animations
